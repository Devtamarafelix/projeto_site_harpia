O que é CSS?

O CSS (Cascading Style Sheets) é a linguagem utilizada para definir a aparência de uma página da web. Com o CSS, podemos alterar cores, fontes, tamanhos, espaçamentos, posicionamento dos elementos e criar layouts mais bonitos e organizados. Enquanto o HTML cria a estrutura da página, o CSS é responsável pelo seu visual, tornando os sites mais modernos e agradáveis para os usuários.

Exemplo:

</> CSS 
h1 {
    color: blue;
    font-size: 32px;
    text-align: center;
}

Nesse exemplo:

  • color altera a cor do texto.
  • font-size define o tamanho da fonte.
  • text-align centraliza o texto na página.

Assim, todo título <h1> ficará azul, maior e centralizado.

O que é JavaScript?

O JavaScript é uma linguagem de programação utilizada para tornar as páginas da web mais interativas e dinâmicas. Com ele, é possível criar botões que respondem ao clique do usuário, formulários inteligentes, animações, menus interativos e muitas outras funcionalidades.

Enquanto o HTML organiza o conteúdo da página e o CSS define sua aparência, o JavaScript adiciona comportamento e interação ao site.

Exemplo:

Veja um exemplo simples de JavaScript:

</> JavaScript 
function mostrarMensagem() {
    alert("Olá, seja bem-vindo!");
}

Esse código cria uma função que exibe uma mensagem na tela quando é chamada. Esse tipo de recurso pode ser utilizado em botões, formulários e diversas outras partes de um site.
